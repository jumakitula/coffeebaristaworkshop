Package Structure & The Role of __init__.py

Understanding Python module namespaces and folder discovery

Without __init__.py (Error)

Python views coffeebaristaagent as an ordinary folder on disk. When app.py executes:

ModuleNotFoundError: No module named 'coffeebaristaagent'
With __init__.py (Working)

Python officially registers the directory as an importable module namespace. It allows app.py to cleanly import functions from coffeebaristaagent.agent.

from coffeebaristaagent.agent import run_barista_agent ✅

Agent Logic & Gemini 3.5 Tools (coffeebaristaagent/agent.py)

Annotated line-by-line function calling and multi-turn state loop

Lines Code Statement Function & Behavioral Explanation Copy
01-04 import json
import os
from google import genai
from google.genai import types 		Imports OS utilities and the modern Google GenAI SDK. The types module contains request objects (GenerateContentConfig) for injecting system instructions, temperatures, and function tools.
06-13 def get_menu() -> str:
  try:
    with open("coffeebaristaagent/menu.json", "r") as f:
      menu_data = json.load(f)
      return json.dumps(menu_data)
  except Exception as e:
    return json.dumps({"error": f"..."}) 		The Tool Function (Function Calling): Passed directly to Gemini's tools=[get_menu] configuration. The model automatically inspects its name and return type, then calls this whenever it needs up-to-date prices, tags, or allergen warnings.
15-17 API_KEY = os.environ.get("GEMINI_API_KEY")
client = genai.Client(api_key=API_KEY) 		Retrieves the API key loaded from .env by load_dotenv() and instantiates the client connection.
19-30 def run_barista_agent(user_message, history=None):
  system_instruction = """You are a barista...
  1. Recommend items ONLY from get_menu().
  2. Do NOT recommend items not in menu.
  3. Ask ONE clarifying question if vague.
  5. Ground recommendations in tags/allergens.""" 		System Persona & Guardrails: Explicitly forbids model hallucination. Restricts the barista to the items in the menu tool and enforces allergen adherence (e.g. strict dairy-free queries).
32-41   chat = client.chats.create(
    model="gemini-3.5-flash",
    config=types.GenerateContentConfig(
      system_instruction=system_instruction,
      tools=[get_menu],
      temperature=0.4
    ),
    history=history
  ) 		Creates an automatic conversational session. Injects tools=[get_menu] so function execution is handled seamlessly. temperature=0.4 strikes an ideal balance between friendly hospitality and factual menu grounding.
43-45   response = chat.send_message(user_message)
  return response.text, chat.get_history() 		Sends customer prompt, internally invokes tool callbacks if required, and returns both the answer text and updated chat memory log to Streamlit.

Launch Streamlit & Cloud Shell Web Preview

Run the web server from the project's root folder.

Terminal Execution Command
python3 -m streamlit run app.py --server.port 8000 --server.enableCORS=false --server.enableXsrfProtection=false
--server.port 8000

Binds server to port 8000 (the standard default port recognized by Google Cloud Shell's web preview).

--server.enableCORS=false

Disables Cross-Origin Resource Sharing locks so the Cloud Shell proxy iFrame loads cleanly without cross-domain blocks.

--server.enableXsrf=false

Suppresses Cross-Site Request Forgery cookie collisions when communicating through Google's dev proxy.

ℹ️
Opening the Web Preview in Google Cloud Shell:

1. In the top right corner of the Google Cloud Shell window, click the Web Preview icon (looks like a monitor with an eye).

2. Select Change Port → enter 8000 → click Change and Preview.

3. Your AI Barista Chat UI will open in a new browser tab ready to take customer orders!
